Accessibility statement

We want everyone to be able to use this website.

This statement applies to the Council Improvements website.

Using this website

We have designed this site so that you should be able to:

  • zoom in up to 400% without text spilling off the screen
  • navigate the whole site using only a keyboard
  • skip straight to the main content of any page
  • use the site with a screen reader
  • read text that has good contrast against its background
  • use the site with animations reduced, if your device is set to reduce motion

We have also tried to keep the wording as simple as possible.

How accessible this website is

We aim to meet the Web Content Accessibility Guidelines (WCAG) version 2.2 at level AA.

This website has not yet been formally tested against these guidelines.

Known issues

  • Links to other websites open in a new tab. Each of these links says so for screen reader users.

Feedback and contact

If you have trouble using any part of this website, or need information in a different format, please tell us.

Contact us using our enquiry form.
